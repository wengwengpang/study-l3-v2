- 每条回复固定"我们在哪 / 这步为什么 / 模式归属 / prompt / 关键点配反例 / 审查清单 / 反馈模板 / 窗口体感 / 下一步"。例：行 3167-3313、3638-3795、3902-4169。

- 选择题按"推荐 B + 一句理由"。例：行 3143、3339-3347、3411-3412、4743。
- 每个决策后说清"为什么这么做 + 反例"，比如行 3267-3271、3729-3736。

- 不信"成功"二字，要贴真实输出（行 4131、4351）。
- 老师自己多次提"诚实"、"不脑补"、"反模式 1"（行 2974、3090、4232）。

- 长回复末尾给"填空模板"让学生回（行 3149-3153、3863-3879）。
- 大幅让学生"选择"，决策点由学生拍（行 3885-3897）。
