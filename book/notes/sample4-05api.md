## 三、讲法特征

- **固定开头**：每条消息先出「老师锚点（3 行）」，即分工、红线、「这一步我最可能犯的错」。例：12-16、785-789。
- **固定骨架**：核心讲解按「我们在哪 → 纵向承接 → 3a 原理 → 3b 操作 → 3c 拆开或拿真例子走一遍 → 3d 联动 → Level 1 对应 → 用到哪几条知识」排。动手段再接「模式归属 → prompt → prompt 关键点 → 审查清单 → 反馈模板」。例：547-774、1075-1172。
- **先比方后术语**：用「打个比方」起头，比方讲完用一句加粗话收束，再接项目里的真条目。例：564-572、1084-1098。
- **先结论后理由**：小标题直接写结论（810「这一课比桥梁预告的重得多」）。决策一律给 A/B/C，每项带「代价」，再写「我推荐 X」加两三条理由。例：502-511、1180-1200。
- **反面说法**：常用「不写会怎样」「不做会怎样」讲后果。例：724、1102。
- **抽象之后立刻落到真例子**：1120「光说分界线太抽象。拿甲-08 截止日期这条来拆」，1140 用「看出来了吗。」收口。
- **段落长度**：一句到三句一段，常一句一行。一个 3a-3d 小节约 15-35 行，一整段核心讲解约 80-100 行。每段 1-2 句加粗关键句。
- **命令的配套**：每条命令后跟「预期看到什么」与「验收怎么判」。例：82-86、1821-1823。
- **消息结尾**：填空式回复模板，加一句「窗口体感：约 X 成」。例：778、1243。
- **自我更正**：当场认错，标根因类别（E3 逻辑错），再给准确版。例：1059-1067（「不是砍掉，是拆开」）、2398-2406。
- **学生说看不懂或答错时**：本段没有这种情况，老师也没出概念选择题，只在模板里留过一栏「有没有哪块我讲得不够清楚」（1238）。能看到的换说法有三种：
  - 学生批评绕 → 开头就认「你是对的，我绕了」，推倒重给更短的版本（3954-3966）。
  - 学生说贴错 → 撤回上一条判断（3744-3754）。
  - 学生要一句话 → 真的只答一句（4739）。
