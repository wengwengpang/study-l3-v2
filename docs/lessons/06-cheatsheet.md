# Lec 6 速查卡 · CLAUDE.md 第三层

【一句话】宪法封顶 = 决策边界(语义层，何时喊主人) + 权限系统(机械层，CC 手伸到哪)。两轴垂直。

【D1-D7】判据 = 可逆吗？影响多大？可逆小影响→自行；不可逆大影响→喊你。
D1 范围 / D2 数据结构(可空加列自行,drop 有数据表必喊) / D3 权限口径 / D4 选型(砸墙贵) / D5 不可逆(双确认+回滚)
D6 需求验货(已验证/假设/教学驱动,横切所有需求)
D7 元触发器(罩在 D1-D6 上,没把握或藏取舍就停。口令:有没有藏着该我拍的取舍?)

【settings.json 三档】allow 绿(自刷卡) / ask 黄(按铃喊你) / deny 红(焊死)。
撞门顺序:deny→ask→allow,红牌永远赢。绿牌可大方,红牌是安全网。
黄牌别塞满(否则审批疲劳,护栏垮)。

【两轴】机械层只挡得住能变命令的动作(rm/drop/写 prisma);纯判断(范围/口径/来源/藏取舍)靠 CC 读宪法自觉。手用铁墙,脑用宪法。

【新规则】66:约束 CC 的配置文件学生亲写(利益冲突+攻击面)。
【验证】JSON 写对≠CC 识别(反模式 3)。必跑 /permissions 确认三档。信仰二:验证先于信任。
