# 补课 05-API · 速查卡（第一窗口）

> 去留：长期。

## 两条裁决

API-1 · 字段的真相归共享 Zod schema。
契约只写接口层：清单、方法、路径、鉴权级别、退回映射、响应外壳、全局约定。
每个接口点名所用 schema，字段本体留 05-类型。
三份文件各管一段：PRD 管能不能，契约管怎么调，schema 管长什么样。

API-2 · 创建项目不依赖角色。任何已登录用户可建，创建者自动成为负责人。
只挂 AuthGuard，不挂 AuthzGuard。
理由：角色按项目划分，创建时项目不存在，用户没有角色，Guard 要的路径项目 id 也没有。
权限矩阵「创建项目」那一格该标「不适用」，不是改填另一个值。
项目数量上限本版不设，进 BACKLOG 32。

## 三条新规

规则 71 · 编号序列按落点分。落项目文件走项目序列，落课程规则直接编规则号。
规则 72 · 持久文档内部引用不写行号，写小节名。行号只用于当场举证。
规则 57 · 删第 12 项（人工确认权限模式），自检退回 11 项，改机械检查。

## 一条新反模式

43 号 · 把易碎引用写进要长期存活的文档。
行号是位置坐标，文件一增删行就指错，且不同位置偏移量不同，无法统一修复。
判据同 24 号：看这条信息要活多久。

## 第二窗口补记

### 十七条裁决（API-3 到 API-19）

外壳含义写契约，字段归 schema（3）。看不见的任务，界面显示「权限不足」（4）。
主参考 Zalando（5）。前缀 /api，Nginx 不剥，不加版本（6）。Next.js 不写接口（7）。
凭据用 HttpOnly Cookie，只收 Cookie（8）。SameSite=Lax（9）。30 天无空闲超时，登记为偏离（10）。
跨站请求伪造用 NestJS 自带防护（11）。本地 rewrites 同源（12）。浏览器用相对路径（13）。
状态码 401、403、400、409、500，不用 422（14）。看不见回 404，看得见不许做回 403（15）。登录失败 401（16）。
错误外壳 RFC 9457（17）。成功不包，列表顶层是对象（18）。中文提示前端按 type 出（19）。

### 标准怎么用

按层定先后：协议、安全、框架、设计规范、自定。同层打架列出来拍。
每条分必须、建议、可选三档。称「标准」必给原文。登记在 docs/arch/STANDARDS.md。

### 三句话记住

看不见回 404，不许做回 403。
SameSite 只是加一层保险，顶替不了正式防护。
AI 的推荐要对着标准原文核。

## 第三窗口补记

### 十一条裁决（API-20 到 API-30）

401 带 WWW-Authenticate: Session（20）。「权限不足」拆成看不见 404、不许做 403（21）。
字段与查询参数用 camelCase，偏离 Zalando（22）。各层抛性质，全局过滤器一处翻码（23）。
type 字面值归 schema（24）。成功 200、201、204，Location 有地址才带（25）。
instance 用 urn:uuid:（26）。只收 JSON，不对回 415（27）。
唯一约束撞车由 Repository 翻成冲突（28）。跨站被拒单列，回 403（29）。外壳三个 schema 定主体（30）。

### 三句话记住

各层只说为什么退，统一出口一处翻成码。
子代理一轮一件：先核对，拍完再起草。
