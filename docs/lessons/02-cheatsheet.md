# 第 2 课速查卡

📍 位置:Phase 0 第 3 步,激活 pm 产出 PRD。

🎯 一句话:pm 是边界守护者,把用户研究变成每条来源都经真人确认的 PRD。

📋 关键模板
- 用户故事:作为<角色>,我想<动作>,以便<价值>。
- 验收标准:给定<前提>,当<动作>,则<预期>。必须可测。
- 角色干活 prompt 第一句:先读你自己的定义文件 .claude/agents/<name>.md。
- 文档角色权限:只给 Read。
- 来源标注:真人确认 / AI 假设(未验证),不许擅自升级。

🐛 常见坑
- 验证只验内容,不验落盘+识别(3 号)。完整链:内容→ls→file→/agents。
- 把 AI 假设当事实写进正式列表(19 号)。先进假设账本。
- 重要长期意图错放桥梁(24 号)。该进 COURSE_RULES。

🌉 L1 对应:网页版 PRD 假设事实混写;现在 pm 文件+假设账本物理分真假。
