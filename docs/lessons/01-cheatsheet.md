# Lec 1 速查卡 · 用户研究

📍 位置：Phase 0 立项，第 1 课。上承 Lec 0（信仰+地图），下接 Lec 2（PRD）。

🎯 一句话：用 client（问）+ persona（答）两个独立角色做研究，
   用假设账本把「真人确认」和「AI 假设」死死分开。

## 关键产物
- .claude/agents/client.md   研究员，只问只综合，Read 权限
- .claude/agents/persona.md  假设用户，AI 设定，产出全待验证
- docs/design/USER_RESEARCH.md  两栏物理分开的研究报告

## 角色文件骨架（可复制改）
---
name: 角色名
description: 英文描述，CC 靠它判断何时派这个角色
tools: Read
model: sonnet
---
（正文：你是谁 + 硬规则 + 边界。第一条硬规则永远是「先读本文件」）

## 3 个要害
- 拆双角色：一个角色又问又答会自问自答（反模式 5）。
- 诚实关卡：AI 编的需求默认「待验证」，真人审过才升「已确认」（反模式 19）。
- 角色定义由老师出文本，不让 CC 自己编（反模式 18）。

## 常见坑
- 20 号：mkdir 写在 cat 后 → 先建目录再写文件。
- 19 号：图省事全 ✅ → 没经真审的 ✅ 是橡皮图章，等于幻觉盖章。
- 3 号：角色在列表≠设定进脑子 → 硬规则第一条让它先读自己。
