## 这节课做成了什么
接口契约 docs/arch/API_CONTRACT.md 落齐四块：零，管辖范围；一，全局约定九个小节；二，接口清单 17 个（auth 4、projects 7、tasks 6）；三，裁决汇总 API-1 到 API-59。字段的唯一真相是共享 Zod schema，契约只点名 schema（API-1）。

## 最该记住的几条
- 状态码只用 400、401、403、404、409、500，不用 422（API-14）。看不见回 404，看得见不许做回 403（API-15）。
- 错误外壳照 RFC 9457；成功响应不包一层（API-17、API-18）。
- 会话存在库里，凭据放 HttpOnly Cookie，跨站防护用 NestJS 自带（API-8、API-11）。
- 邮箱不分大小写唯一，用 citext（ADR-DB-008）；密码规则照 OWASP 现行（PRD 审定决策 D20）。

## 这节课长出来的做法
- 专业做法先照行业标准，没有才照主流，再没有才自定（HARNESS 原则 23）。
- 报进度从交付物清单导出，先跑覆盖核对（规则 87）。
- 改文件先把改后全文拼进副本，落完逐字节比（原则 22）。
- 到哪个时刻就读检查单那一张；一轮中断后先复查再接着（卡 14、原则 24）。
- 搜不到不等于没有（反模式 47）。
